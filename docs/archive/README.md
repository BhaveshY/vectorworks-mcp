install paths that no longer exist in 1.0 (for example `vw_ping`,
`vw_catalog`, `scripts/bootstrap-claude-code.ps1`, the modal Python listener
and `%LOCALAPPDATA%\VectorworksMCP\<version>`). Do not follow them; use
`README.md`, `INSTALL.md` and `docs/V1_CONTRACT.md` instead.
